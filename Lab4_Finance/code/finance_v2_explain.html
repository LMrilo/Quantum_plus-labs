Quantum Portfolio Optimization

Finance & Industry Applications — QUBO (Quadratic Unconstrained Binary Optimization), QAOA (Quantum Approximate Optimization Algorithm), and Real Asset Data

75 min Prerequisites: Labs 1–2 (Lab 4 helpful, not required) No finance background needed AAPL · MSFT · JPM · XOM QUBO → QAOA

This lab applies a quantum optimization algorithm to a real financial problem: selecting the best 2-asset portfolio from {AAPL, MSFT, JPM, XOM}. Everything it needs beyond Labs 1–2 is explained on this page. If you did Lab 4, you have met the same algorithm on a small graph problem, and the optional boxes point out the connections. The route has three steps: write the investment choice as a cost over 0/1 decisions (a QUBO, Part A), rewrite that cost as an operator on qubits (an Ising Hamiltonian, see "From bits to qubits" before Part C), and let a short quantum circuit (QAOA) search for the cheapest bit string (Part C).

 The Scaling Argument

For $n = 4$, $K = 2$ there are only 6 portfolios, and a laptop checks them all instantly. For $n = 50$, $K = 10$ there are $\binom{50}{10} \approx 10^{10}$: checking every one becomes impractical, and real desks use classical heuristics instead. QAOA's circuit grows only as $\mathcal{O}(n^2)$ gates per layer, which is why it is studied for this problem. Whether it can beat the best classical heuristics is an open research question. This lab shows what it does and does not deliver today.

Part A: Interactive QUBO Builder

Symbols and finance terms used on this page
  • The four assets: AAPL (Apple), MSFT (Microsoft), JPM (JPMorgan Chase), XOM (ExxonMobil). All figures are annualised, estimated from 2020–2024 prices.
  • $x_i \in \{0,1\}$ (decision): $x_i = 1$ means asset $i$ is in the portfolio. A portfolio is a 4-bit string $x$. Declared simplification: each chosen asset receives the same amount of money; choosing weights (the full Markowitz problem) is not modelled.
  • $K$ (budget): how many assets we must pick. Here $K = 2$, so exactly two $x_i$ equal 1: $\binom{4}{2} = 6$ possible portfolios.
  • $\mu_i$ (expected return): the average yearly gain of asset $i$ (AAPL: $\mu = 0.34$, i.e. 34% a year). $\mathrm{diag}(\mu)$ is the matrix with the $\mu_i$ on its diagonal and zeros elsewhere.
  • $\Sigma$ (covariance matrix): $\Sigma_{ii} = \sigma_i^2$ is the variance of asset $i$; its square root $\sigma_i$ (the volatility; AAPL: 29%) is what this page calls risk. $\Sigma_{ij}$ ($i \neq j$) measures how assets $i$ and $j$ move together: large and positive means they tend to rise and fall together, so holding both diversifies little.
  • $\lambda$ (risk aversion): how much one unit of variance costs compared with one unit of return. Slider left (small $\lambda$): growth-seeking investor; slider right: cautious investor.
  • $\lambda_\mathrm{pen}$ and $P$ (budget penalty): $P$ has $1 - 2K = -3$ on the diagonal and $1$ everywhere else, so $x^TPx = (\sum_i x_i - K)^2 - K^2$. Every portfolio with exactly $K$ assets receives the same constant $-\lambda_\mathrm{pen}K^2 = -12$; any other count receives more.
  • $Q$ and the cost $x^TQx$: one number per portfolio, $x^TQx$ $= \lambda\,x^T\Sigma x - \mu^T x + \text{penalty}$; lower is better. Writing the whole problem as one such matrix over 0/1 variables is called a QUBO (Quadratic Unconstrained Binary Optimization).

Adjust the risk-aversion parameter $\lambda$ and observe how the QUBO matrix $Q$ changes and which portfolio becomes optimal. Diagonal (own risk − return + budget penalty): green if negative. Off-diagonal (joint risk + budget penalty): neutral.

How to read the numbers. Each diagonal entry has three pieces: $Q_{ii} = \lambda\Sigma_{ii} - \mu_i + \lambda_\mathrm{pen}(1-2K)$. At $\lambda = 1$, AAPL gives $0.0841 - 0.340 - 9$ $= -9.2559$: the $-9$ is the budget penalty, and the small remainder $-0.2559$ is the finance. Likewise every two-asset portfolio's cost is its finance cost $\lambda\,x^T\Sigma x - \mu^T x$ plus the same constant $-\lambda_\mathrm{pen}K^2 = -12$; AAPL+MSFT's $-12.3354$ is $-0.3354 - 12$. The constant never changes the ranking. Only the last digits matter, and they are close: at $\lambda = 1$ all six portfolios lie within $0.21$ of each other.

From bits to qubits. A qubit measured in the computational basis gives 0 or 1, exactly one decision bit $x_i$. The Pauli operator $Z_i$ has value $+1$ on $|0\rangle$ and $-1$ on $|1\rangle$, so $x_i = (1 - Z_i)/2$ is 0 or 1 in the same cases. Substituting this into the cost gives an operator $H_C$ whose value on the basis state $|x\rangle$ is the portfolio cost, up to a constant. Pairs of assets become $Z_iZ_j$ terms with coefficient $Q_{ij}/2$, and each asset alone becomes a $Z_i$ term with coefficient $h_i = -\tfrac12\sum_j Q_{ij}$. A sum of $Z$ and $ZZ$ terms that plays the role of an energy is called an Ising Hamiltonian (after a physics model of magnets). The cheapest portfolio is its lowest-energy basis state, the ground state: minimising cost and finding the ground state are the same task. Because the substitution drops a constant, energies of $H_C$ are the QUBO costs shifted by a fixed amount (here $9.2294$): the best cost $-12.3354$ corresponds to the ground-state energy $-3.1060$.

Part C: QAOA Result Simulator

QAOA in one box — Quantum Approximate Optimization Algorithm (developed in full in Lab 4; everything needed here is below)
  1. Start: a Hadamard gate on every qubit gives all $2^4 = 16$ bit strings the same probability, $1/16$.
  2. Cost layer $e^{-i\gamma H_C}$: gives every bit string a phase proportional to its cost; $\gamma$ is an angle we choose. A phase alone changes no measurement probability. Each $Z_iZ_j$ term is built as CNOT–$R_z$–CNOT: the first CNOT writes "do bits $i$ and $j$ differ?" onto qubit $j$, the $R_z$ applies a phase that depends on that answer, and the second CNOT undoes the first. Each single $Z_i$ term is one $R_z$ on qubit $i$.
  3. Mixer layer: an $R_x(2\beta)$ rotation on every qubit makes bit strings that differ by one flip interfere, and this turns phase differences into probability differences.
  4. Repeat cost + mixer $p$ times (here $p = 1$ or $2$): $2p$ angles in total.
  5. Tune: run the circuit many times, average the cost of the outcomes (this average is written $\langle H\rangle$ and called the expectation value), and let an ordinary classical optimizer (COBYLA, a standard derivative-free routine) change the angles to lower that average. Nothing in this step is quantum.
The hope is that cheap bit strings end up with high probability. Whether that happens here is what this Part tests.

The circuit has the same three stages as in Lab 4: a Hadamard layer ($\mathrm{H}$ on every qubit), a cost layer, and a mixer ($R_x$ on every qubit). The cost layer now has one CNOT–$R_z$–CNOT block per $Z_iZ_j$ term, with angles proportional to $Q_{ij}$, plus one $R_z(2\gamma h_i)$ on each qubit for the single-$Z$ terms that carry the return information. Part D: Qiskit Python Implementation

Exercises 1–3: QUBO, QAOA, Frontier Analysis Open Colab Notebook

The script prints the cost $x^TQx$ of the six portfolios; each equals the finance cost minus the constant 12 (see Part A).

import numpy as np, math, itertools
from qiskit.quantum_info import SparsePauliOp

# ── Real asset data (AAPL, MSFT, JPM, XOM — annualised 2020-2024) ──────────
MU    = np.array([0.340, 0.270, 0.150, 0.220])
SIGMA = np.array([
    [0.0841, 0.0588, 0.0313, 0.0203],
    [0.0588, 0.0729, 0.0272, 0.0170],
    [0.0313, 0.0272, 0.0576, 0.0294],
    [0.0203, 0.0170, 0.0294, 0.1225]])
TICKERS = ['AAPL', 'MSFT', 'JPM', 'XOM']

def build_qubo(lam=1.0, lam_pen=3.0, K=2):
    n = len(MU)
    Q = lam * SIGMA - np.diag(MU)        # risk-return objective
    P = np.full((n,n), lam_pen)          # penalty off-diagonal
    np.fill_diagonal(P, lam_pen*(1-2*K)) # penalty diagonal
    return Q + P

def portfolio_cost(bits, Q):
    x = np.array(bits)
    return float(x @ Q @ x)

# Enumerate all feasible portfolios (K=2 assets from 4)
Q = build_qubo(lam=1.0)
for combo in itertools.combinations(range(4), 2):
    x = [1 if i in combo else 0 for i in range(4)]
    names = '+'.join(TICKERS[i] for i in combo)
    print(f"{names:15s}  cost={portfolio_cost(x,Q):.4f}")
